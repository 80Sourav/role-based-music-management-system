# Role-Based Music Management System

A backend application built using Node.js, Express.js, and MongoDB for user authentication, role-based authorization, and music management.

## Tech Stack

- Node.js
- Express.js
- MongoDB and Mongoose
- JSON Web Tokens (JWT)
- ImageKit

## Features

- User registration and login
- JWT-based authentication
- Role-based authorization
- Protected API routes
- Music file uploading using ImageKit
- MongoDB integration

## Installation

1. Clone the repository.
2. Run `npm install`.
3. Create a `.env` file using `.env.example` as a reference.
4. Configure the required environment variables.
5. Start the backend using the script defined in `package.json`.
